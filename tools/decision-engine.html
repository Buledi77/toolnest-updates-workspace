No fabricated data

Scoring uses only verified structured data. When data is missing, the engine shows "unknown" instead of guessing.

Scoring methodology

Each tool receives two separate metrics: a Fit Score (how well it matches your criteria) and Evidence Confidence (how much verified data supports the recommendation).

Fit Score (out of 90)

Use Case Match (40 points)

How many of your selected use cases match the tool's verified use case tags. If no use case data exists, this dimension is skipped rather than penalized.

Category Match (20 points)

Whether the tool belongs to one of your selected categories.

Best For Match (20 points)

How many of your selected use cases match the tool's "best for" descriptions. If no best-for data exists, this dimension is skipped.

Platform Match (10 points)

Whether the tool is available on your selected platforms. If no platform data exists, this dimension is skipped.

Evidence Confidence

Shows how much verified data supports each recommendation:

Strong evidence

3+ verified data fields (use cases, category, best-for, platform, pricing). Recommendation is well-supported.

Moderate evidence

1-2 verified data fields. Some gaps remain — check the full profile for details.

Limited evidence

Few or no verified data fields. Recommendation may be based on category match alone.

⚠️ Three-state reasoning: When data is missing (UNKNOWN), the engine does not count it as a match or mismatch — it simply skips that dimension and reports the gap. This prevents tools with incomplete data from being unfairly ranked. Learn about our data standards.
