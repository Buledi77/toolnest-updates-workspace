Cursor review: AI code editor pricing and features

Cursor is an AI-native code editor with chat and agent modes, part of The X Subscription. This review covers current plans, usage limits, and model access.

What Cursor is for

Cursor is an AI-powered code editor that combines chat-based coding assistance with agent modes. It supports Cursor's own models and third-party models like Claude, GPT, Gemini, and Grok. It is part of The X Subscription, shared with Grok and X. It is most useful when AI-assisted editing is a core development workflow rather than an occasional helper.

Our decision

Cursor is a strong candidate for developers who want an AI-native code editor and teams using The X Subscription ecosystem. It is a poor value for someone who only needs occasional code completions in an existing editor.

What Cursor covers

AI code editing

Chat and agent modes for code generation, refactoring, and debugging.

Multi-model support

Cursor models and third-party models (Claude, GPT, Gemini, Grok) at API list price from prepaid credit.

The X Subscription

Shared subscription with Grok and X — usage draws from the same pool.

Legacy plans

Existing customers on legacy plans (Hobby, Pro, Pro+, etc.) retain their plans until they switch or cancel.

Which Cursor plan fits your workload?

Start with the smallest plan that covers the usage you actually need. Plus ($8/mo) covers Cursor's own models only. Premium ($30/mo) adds third-party model access. Super and Ultra are for heavy agent users who need priority access. Teams and Enterprise add organizational controls.

Who Cursor is best for, and who should skip it

Best for

  • Developers wanting an AI-native code editor.
  • Teams using The X Subscription ecosystem.
  • Heavy agent users who need multi-model access.

Not best for

  • Someone who only needs occasional code completions in an existing editor.
  • A buyer who prefers editor-agnostic AI tools like GitHub Copilot.
  • A team that cannot justify usage-based billing uncertainty.

Limitations and cost traps

  • Usage-based billing — heavy agent use can exhaust credits quickly.
  • Third-party models billed separately at API list price on new plans.
  • Legacy plans not available to new customers.
  • No offline mode.
  • Free plan has limited AI usage with no third-party model access.

Free access and trial reality

Cursor offers a Free plan with limited AI usage and no third-party model access. It serves as an entry point for trying the editor, but the limits are not sufficient for regular development work.
