# Adding a Tool

Use this workflow for a new Decision Graph record. It does not automatically create a public page.

1. **Official source** — confirm the official domain, product identity, pricing, plans, limits, availability, and relevant documentation.
2. **Structured record** — add a stable ID and slug under `data/tools-v2/`; populate only known discovery and editorial fields.
3. **Evidence ledger** — add source records and one claim record per significant factual assertion, including region, currency, billing term, verification date, and stale deadline.
4. **Validators** — run the Decision Graph, evidence, freshness, and affiliate-separation checks plus the tests.
5. **Editorial tier** — start at Tier C unless evidence, demand, and original decision value justify Tier B or A.
6. **Preview** — review generated or future-consumer output, links, metadata, structured data, accessibility, and mobile behavior.
7. **Publishing eligibility** — publish only if the tier, intent registry, canonical, indexability, sitemap policy, and QA gates all pass.

Never use an affiliate URL as the official URL. Never invent pricing, ratings, testing, popularity, or availability.
